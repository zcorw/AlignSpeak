# 兼容与发布状态

最后更新：2026-08-20

## 1. 当前结论

- 实现状态：完成。
- 自动化状态：本功能的后端、前端、媒体与配置验证已纳入本地回归和 CI。
- 发布状态：**待 iOS 真机验证，不得标记为生产发布就绪**。
- 正式支持目标：发布时最新稳定 iOS 的 Safari 普通标签页。
- Chrome iOS：只做核心兼容验证；通过后可标记“兼容”，不共享 Safari SLA。
- 主屏幕 PWA：尽力而为验证，不作后台稳定性承诺。

“切 App、锁屏、熄屏仍持续”和控制中心播放/暂停是优化目标。即使真机测试通过，也不能把 WebKit 在系统压力下不回收页面描述为稳定保证。

## 5. 发布判定

只有以下条件同时满足，才可把 Safari 状态从“待真机验证”改为“可发布”：

1. 当前提交的所有 CI 检查通过，包括 API 镜像构建与镜像内 FFmpeg smoke。
2. IOS-SAFARI-01 至 IOS-SAFARI-06 在发布时最新稳定 iOS 上完成并留下证据。
3. 阻断级缺陷为零；后台中断若来自已知平台限制，产品文案明确为尽力而为。
4. Worker、磁盘容量和失败率观测可用，并已验证回滚到前一 Web/API 镜像。

Chrome iOS 与 PWA 的结果独立记录，不阻塞 Safari 首发，也不能继承 Safari 的结论。
